# Конспектор

Сайт по образцу zachet.app: нейросеть превращает запись диктофона, аудио/видео, PDF, Word, фото, текст или ссылку (статья, YouTube, PDF) в чёткий структурированный конспект. Из конспекта одной кнопкой: флеш-карточки, тест с проверкой, шпаргалка, «объяснить проще», интеллект-карта, план ответа и перевод на любой язык.

## Запуск

```bash
npm install
cp .env.example .env.local   # вписать ключи
npm run dev                  # http://localhost:3000
```

Нужны ключи (см. `.env.example`):
- `ANTHROPIC_API_KEY` — Claude пишет конспекты, карточки, тесты и перевод, сам читает PDF и фото;
- `STT_API_KEY`, `STT_BASE_URL`, `STT_MODEL` — распознавание речи через Whisper (Groq или OpenAI).

Запасной вариант с оплатой российской картой: Yandex Cloud (`AI_PROVIDER=yandex`, `STT_PROVIDER=yandex`, `YANDEX_API_KEY`, `YANDEX_FOLDER_ID`). Тогда конспекты пишет YandexGPT, голос распознаёт SpeechKit, а фото не поддерживаются.

Другая OpenAI-совместимая нейросеть (например, GLM-5.1 или DeepSeek V4 на Cloud.ru): `AI_PROVIDER=openai`, `LLM_BASE_URL`, `LLM_API_KEY`, `LLM_MODEL`. Распознавание голоса при этом можно оставить на SpeechKit.

## Как устроено

- Next.js 16 (App Router) + Tailwind, всё в одном приложении.
- `src/lib/ai.ts` — выбор нейросети; `yandex.ts` и `claude.ts` — сами вызовы.
- `src/app/api/summarize` — конспект (потоковый вывод). PDF для YandexGPT переводится в текст на сервере.
- Аудио и видео декодируются прямо в браузере (`src/lib/audio.ts`), режутся на фрагменты по 25 с и распознаются параллельно через `src/app/api/transcribe`. Ограничения на длину записи нет, только размер файла до 300 МБ.
- `src/app/api/link` — текст со страницы, субтитры YouTube или PDF по ссылке.
- `src/app/api/extract` — текст из .docx.
- `src/app/api/flashcards`, `quiz` — карточки и тест в строгом JSON.
- `src/app/api/transform` — перевод, шпаргалка, упрощение, интеллект-карта, план ответа.
- Промпты: `src/lib/prompts.ts`. История конспектов хранится в браузере (localStorage).

## Деплой

Проще всего Vercel: импортировать репозиторий, добавить переменные из `.env.example`. Для длинных лекций нужен тариф с таймаутом функций от 300 с.

## Вход для группы

Сайт закрыт для группы ЮФ МГУ-120: войти можно только по логину (имя.фамилия латиницей) и паролю из 6 цифр. Нейросеть отвечает только вошедшим. Список участников и хэши паролей лежат в `src/lib/students.ts`, сами пароли в репозиторий не попадают. Логин можно вводить в любом виде: `lev.kravchenko`, `Lev Kravchenko`, `levkravchenko`.
